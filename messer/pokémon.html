Key Terminology

  • Holo (Holofoil):A card featuring a shiny, reflective foil picture window.
  • Secret Rare: A card with a set number higher than the official set size (e.g., 105/100).
  • PSA: Professional Sports Authenticator, a popular third-party card grading service.
